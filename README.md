# EO Treasury Workbench

This is a static workbench for GitHub Pages.

## Included

- FX Calculator
- Bank Account Modify
- Payment Instruction Generator
- OO Settlement
- Commission Settlement
- Toolbox download for Daily Folder Creator

## Publish

Upload the contents of this `workbench` folder to a GitHub Pages branch or folder.
Open `index.html` from the published GitHub Pages URL.

## Notes

- The toolbox ZIP is static. Recreate it if files in `../temp` change.
- The commission app is copied from `../佣金结算/dist`. Rebuild and copy it again after commission app changes.
